# Приглашение · Кыз узатуу — Аяна

Статичный сайт-приглашение (HTML/CSS/JS, без сборки). Три языка: кыргызча / русский / english.
Анимация конверта, обратный отсчёт, падающие лепестки, форма подтверждения (RSVP) с сохранением ответов в Google-таблицу.

## Структура

```
invite_uzatuu/
├── index.html            — разметка
├── assets/
│   ├── css/styles.css     — стили и анимации
│   ├── js/app.js          — переводы, конверт, таймер, лепестки, форма
│   └── img/               — branch.svg (ветка сверху), corner.svg (углы), sprig.svg (веточки)
├── google-apps-script.gs — код для Google-таблицы (бэкенд RSVP)
└── README.md
```

## Как открыть локально

Из папки проекта:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000 в браузере.
(Просто двойным кликом по `index.html` открывать не стоит — часть браузеров не подгружает `assets/` по протоколу `file://`.)

## 1. Публикация на бесплатном хостинге

### Вариант A · GitHub Pages (рекомендую)

1. Создайте репозиторий на GitHub (например `invite-aiana`).
2. Загрузите в него все файлы из этой папки (можно через веб-интерфейс: **Add file → Upload files**).
3. **Settings → Pages → Build and deployment**: Source = `Deploy from a branch`, Branch = `main`, папка `/ (root)` → **Save**.
4. Через ~1 минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/invite-aiana/`.

Через терминал:

```bash
cd invite_uzatuu
git init && git add . && git commit -m "invite"
git branch -M main
git remote add origin https://github.com/<логин>/invite-aiana.git
git push -u origin main
```

### Вариант B · Netlify (как в примере)

- Зайдите на app.netlify.com → **Add new site → Deploy manually** и перетащите папку `invite_uzatuu` целиком.
- Netlify выдаст адрес вида `https://<имя>.netlify.app`. Имя можно поменять в **Site settings → Change site name**.

Оба варианта бесплатны и дают HTTPS.

## 2. RSVP → Google-таблица

Форма отправляет «Имя» и «Кол-во гостей» в вашу Google-таблицу через бесплатный Google Apps Script.

### Настройка (5 минут)

1. Создайте новую Google-таблицу на https://sheets.new
2. В меню: **Расширения → Apps Script**.
3. Удалите пример кода и вставьте содержимое файла [`google-apps-script.gs`](google-apps-script.gs). Сохраните (💾).
4. Сверху выберите функцию **`setup`** и нажмите **Выполнить** — Google попросит разрешение, согласитесь (это создаст лист «RSVP» с заголовками).
5. Нажмите **Развернуть → Новое развёртывание**:
   - Тип: **Веб-приложение** (значок шестерёнки → «Веб-приложение»).
   - **Запуск от имени:** Я (ваш аккаунт).
   - **У кого есть доступ:** Все (Anyone).
   - **Развернуть** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. Откройте `assets/js/app.js` и вставьте URL в самую первую строку-настройку:

```js
const RSVP_ENDPOINT = "https://script.google.com/macros/s/......../exec";
```

7. Сохраните, перезалейте файл на хостинг. Готово — ответы гостей будут падать в таблицу.

> Пока `RSVP_ENDPOINT` пустой, форма работает в демо-режиме: показывает «спасибо», но никуда не сохраняет.

### Проверка

Заполните форму на сайте и обновите таблицу — должна появиться строка: дата/время, имя, кол-во гостей, язык.

## 3. Как менять содержимое

| Что | Где |
|-----|-----|
| Имя, тексты, переводы (3 языка) | `assets/js/app.js` → объект `I18N` |
| Дата/время события и отсчёта | `assets/js/app.js` → `EVENT_DATE` |
| Надпись на печати конверта | `index.html` → `<span class="env-seal">Аяна</span>` |
| Цветочное оформление | `assets/img/branch.svg`, `corner.svg`, `sprig.svg` |
| Ссылки на карту (2ГИС / Google Maps) | `index.html`, секция «where» (атрибуты `href`) |
| Цвета оформления | `assets/css/styles.css` → блок `:root` (переменные `--rose`, `--gold`, `--blush`, `--cream`…) |
| Заголовок вкладки | `index.html` → `<title>` |

День недели в датах прописан вручную (`среда / шаршемби / Wednesday`) — при смене даты поправьте и его.
